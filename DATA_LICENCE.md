All map data in this repository and in the published course files is derived
from OpenStreetMap.

https://opendatacommons.org/licenses/odbl/1-0/

Credit: "© OpenStreetMap contributors" must appear wherever this data, or a
map drawn from it, is shown. Every published JSON file carries an `attribution`
field saying so.

Share-alike: a database derived from this data must be offered under the ODbL.
The code in this repository that produces the data is MIT licensed and is
separate from the data.

The test fixtures in `tests/fixtures/` are extracts of OpenStreetMap data and
are covered by the same licence.
